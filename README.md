# UPYOG Property Tax Analytics Dashboard

A premium, interactive, and high-fidelity Property Tax Analytics Dashboard built for the **UPYOG** multi-tenant platform. The application provides data aggregates, comparisons, search/filter registries, and a conversational AI Copilot (assistant) for 1,000 property tax records across 10 Indian cities.

---

## 🚀 Live Demo & Visual Highlights

- **Harmonious Dark Theme**: Sleek background gradients, glow effects, and modern fonts (`Plus Jakarta Sans` and `Outfit`).
- **Glassmorphic Panels**: Blurred transparent containers that provide a modern desktop feel.
- **Dynamic Micro-animations**: Micro scale-up effects on buttons/cards, animated typing loaders, and celebration confetti on data milestones.

## 🎯 Task & Feature Checklist

All evaluation parameters outlined in the Intern Assessment prompt have been implemented:

### ✅ Task 1: KPI Dashboard (45 Points)
- **4 Real-time KPI Cards**:
  1. **Total Properties Registered**: Total count of property records.
  2. **Total Properties Approved**: Count of properties with status `Approved`.
  3. **Total Properties Rejected**: Count of properties with status `Rejected`.
  4. **Total Collection (Rs.)**: Total collected amount (`collection_inr`) for the tenant.
- **Dynamic Filtering**: A tenant dropdown filter allows filtering the entire page instantly (All Cities + 10 specific Indian cities).
- **Secondary KPIs**: Custom visual progress bars for approval/rejection ratios, and real-time computation of **Collection Efficiency %** relative to annual demand.

### ✅ Task 2: Comparison Chart (10 Points)
- **Interactive Multi-Tab Visualizations** powered by `Recharts`:
  1. **Revenue Collections comparison**: Side-by-side comparison of annual tax demand vs actual tax collections for all 10 cities.
  2. **Status Breakdown (Bonus Chart)**: A stacked/grouped bar chart mapping counts of `Approved`, `Pending`, and `Rejected` properties across all 10 cities.
  3. **Property Category Distribution**: A donut chart illustrating properties breakdown by category (Residential, Commercial, etc.) with custom hover states and legends.

### ✅ Task 3: AI Chat Assistant (25 Points)
- **UPYOG AI Copilot Panel**:
  - Integrated with **Google Gemini 1.5 Flash** using the official Google Generative AI SDK.
  - Automatically feeds an aggregated, mathematically pre-calculated dataset summary into the model's system instructions.
  - Correctly and instantly resolves quantitative queries:
    - *"Which city has the highest total collection?"*
    - *"How many properties are rejected in Mumbai?"*
    - *"What percentage of Delhi properties are approved?"*
    - *"Compare Pune and Jaipur registrations."*
  - **Quick Suggestion Chips** to let users launch sample questions with a single click.
  - **Dual API Key Routing**: Developers can specify the key in `.env` or input it directly in the UI. Inputs are saved securely in browser `localStorage`.
  - **Markdown Response Rendering**: Renders bold text, lists, and HTML tables generated by Gemini.

### ✅ Code Quality & Structure (20 Points)
- Organized directory structures:
  - `src/components/`: Modular React components.
  - `src/utils/`: High-performance aggregators and Gemini service wrappers.
  - `src/data/`: Static property datasets.
- Clean Tailwind styles in `src/index.css`.
- Comprehensive markdown documentations.

## 🛠️ Installation & Setup

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### 1. Clone & Navigate
```bash
git clone <repository-url>
cd Propertysecond
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Gemini AI API Key
We support two methods for testing:

#### Method A: Env Configuration (Recommended)
1. Copy `.env.example` to a new file named `.env` in the project root:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` and paste your Google Gemini API key:
   ```env
   VITE_GEMINI_API_KEY=AIzaSy...
   ```

#### Method B: Interactive UI Entry
If you do not configure a `.env` file, the UPYOG AI Copilot will display an elegant dialog overlay asking for your API Key. Simply paste it there, and the dashboard will save it to local storage.

> 💡 **Get a free API key** in seconds at [Google AI Studio](https://aistudio.google.com/).

### 4. Start the Application
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for Production
To bundle the project for production distribution:
```bash
npm run build
```
